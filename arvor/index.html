Arvor Linux

An atomic but not immutable distribution using EXT4 or XFS with LVM. The root stays a normal writable volume — packages change it through snapshotted transactions, and if anything goes wrong you roll back.

github ↗

The toolkit

01

nsm

The snapshot engine. nsm takes LVM snapshots of the root on demand and automatically around package operations rolls the system back to any of them, and cleans up after itself.

02

weld

The package manager. weld runs apt-compatible transactions against minisign-signed repositories inside a sandboxed tree, and every transaction is backed by a snapshot, so installs and upgrades can be undone.

03

nflxs

The sandbox runner. nflxs spins up isolated sandboxes of other distributions with their own users, resource limits and syscall filtering for software that lives outside the base system.
